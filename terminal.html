The basics

Each block starts at the beginning of a line with user: (your message) or claude: (the answer). The answer can span many lines and supports Markdown: **bold**, *italic*, `code`, lists, headings, tables and code blocks. Spanish keywords (yo:, [pensar]…) work too.

user: claude what are black holes

claude: A black hole is a **pothole**.

1. It rains
2. A truck drives by

Switch model and effort

user: /model {opus max}     ← opens the picker and chooses by itself
user: /model sonnet         ← direct switch, no picker
user: /effort high          ← changes only the effort
user: ultrathink explain    ← "ultrathink" shows up in rainbow colors

Text inside { } is never typed on screen: it tells the picker which model and effort to choose. Efforts: low, medium, high, xhigh, max, ultracode.

Timing

[think 6]                          ← the spinner spins for 6 s
[think 8 Consulting Hawking]       ← with a custom phrase
[pause 2]                          ← waits 2 s

Without [think], Claude's delay depends on the effort: more effort, longer wait (and the same absurd answer).

Playback modes

AutomaticEverything plays by itself. Space or F8 to start and pause.
My paceEvery key you press types the next letter of your scripted line (9 keys = 9 letters). Enter sends it and hands the turn to Claude. In pickers, each key moves one step toward the scripted option.
FreeYou type for real. When you send, Claude answers with its next scripted turn. /model opens a real picker (arrows, ← → effort, Enter).

Tips

Lines starting with // are comments. If a line of Claude's answer starts with a keyword (e.g. “Todos:”), put a space before it so it isn't read as a new block.
