Sidebar: groups and sessions

One line per group (end it with * for a blue dot). Below it, its sessions starting with - (* marks one as unread). Indent a session to nest it under the one above. Add | branch or | branch 2 for the branch icon. The script's session shows up under “Ungrouped”.

Model picker

One line per model: alias | name | badge (the badge is optional, e.g. “Default”). Leave it empty to use the defaults for the chosen language.

Same script as Claude Code

Every page uses exactly the same format (user:, claude:, [think], tool:…) and, opened from the same folder in the same browser, they share the script: pick another version or the terminal in the Interface selector of the Script tab. Spanish keywords (yo:, [pensar], pregunta:…) work too.

The basics

user: claude what are black holes

claude: A black hole is a **pothole**.

1. It rains
2. A truck drives by

Each block starts at the beginning of a line. Claude's answer can span many lines and supports Markdown: **bold**, *italic*, `code`, lists, headings, tables and code blocks. Lines starting with // are comments.

How each directive looks in Desktop

user: /model {opus max}The cursor opens the model picker, selects Opus, then opens it again and picks Max in the “Effort” submenu. Nothing is typed in the chat.
effortlow · medium · high · xhigh (shown as “Extra”) · max · ultracode (in purple).
user: /effort ultracodeChanges only the effort.
{opus fast}Also turns on “Enable fast mode” in the menu.
[think 8 Phrase]“Phrase” shows up as a live thinking block while Claude thinks for 8 seconds.
reasoning:Collapsible thinking block. Optional title: reasoning: [Concluded it is a pothole] text…
tool:Tool row (web search, command…). The first output line shows next to it; Ctrl+O expands it.
tool-error:A tool that fails.
edit: fileA file edit with a diff (@@ N, - removed, + added).
todos:Task list card: [x] done · [>] in progress · [ ] pending.
question:Claude asks you a question. One line per option: - Label | description (“Other” is added for you). [choose N] picks the answer. Several question: blocks in a row become one card with pages (“1 of 3”); while it waits, the status says “Needs your input”, and at the end a card sums up the answers.
confirm:A suggestion card with buttons: the header is the question, plain lines are the text above it and - lines are the buttons (the first one is the main one). [choose N] clicks one; its label is sent as your reply and the lines after it are Claude's next turn.
permission:“Allow Claude to use Bash?” card. [choose 1] = Allow once, 2 = Always allow, 3 = Deny.
[tokens 3.5M]The token counter in the status line climbs steadily to that number while Claude works, and the turn ends with “Worked for 9s · 3.5M tokens”. Accepts 800k, 1200000… Without it, the counter still climbs to a realistic amount for the answer.
[error]Red notice. Without text it shows the classic “capacity constraints” message.
[info text]A small gray system line.
[interrupt]Claude's answer gets interrupted.
[pause 2]Waits 2 seconds.
/compact · [compact]“Compacting our conversation…” animation.
/clear · [clear]The cursor clicks “New”.
[title Text] · @titleSession title (shown after the first answer and in the sidebar). Without them, the first message names the session. Once named, it never changes: a later [title] is ignored until /clear starts a new session.
@greetingHome screen greeting (default “What’s up next, <user>?”).
@sessions … @mobyNumbers on the home screen stats card: @sessions, @messages, @totaltokens, @activedays, @peakhour, @favoritemodel, @moby.
@branch · @connectorsSession panel on the right: the git branch (default main) and how many connectors are connected.
[context 4%] · @contextContext left (same as in the terminal). The session panel shows how much is used (here 96%); without it, the percentage grows with the tokens Claude spends.
@outputsFiles listed under “Outputs” from the start (comma separated). Every edit: adds its file there too.

[mode] only exists in the terminal version; it is ignored here.

Modes

My paceEvery key you press types the next letter of your scripted line (9 keys = 9 letters). Enter sends it and Claude answers. In the model picker, permission cards and questions, each key is one cursor click; Enter completes everything.
AutomaticEverything plays by itself. Space or F8 to start and pause.
FreeYou type for real; Claude answers with its next scripted turn. You can use the real mouse on the model picker and permission cards.

In any mode you can really click the model picker, the thinking blocks and the permission buttons.
